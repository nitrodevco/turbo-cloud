AI tool works from: `AGENTS.md` (the coding contract, and which `docs/rules/` page to read for the
area you touch) and `CONTEXT.md` (where code belongs and which type owns what).

Write rules in those files or in the `docs/rules/` page for their area, not here: a rule written
here is one that Codex and Copilot never see.
