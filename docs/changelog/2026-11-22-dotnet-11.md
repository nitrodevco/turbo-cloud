title: ".NET 11 and C# 15"
date: 2026-11-22
pr: turbo-cloud@938971d0
breaks: yes
who: "plugins with a project of their own, and hotels that build the server."
---

**What**: The server targets `net11.0` and builds with the .NET 11 SDK (`global.json`: 11.0.100).
EF Core and the MySQL provider (`Microting.EntityFrameworkCore.MySql`) are 11.0.0, and the server
compiles plugins as C# 15, so a plugin may use unions, `closed` classes, `with(...)` arguments in
collection expressions and labeled `break`/`continue`.

**Breaks plugins**: a plugin project that targets `net10.0` no longer builds against the server's
assemblies, which are `net11.0`, and an SDK 10 compiler cannot load the policy analyzer
`Turbo.Plugin.props` brings in. A type named `union` or `closed` now needs `@`.

**Action**: `docs/upgrading.md`, "To .NET 11". A hotel installs the .NET 11 SDK before it deploys
this version (`scripts/ploi/README.md`, step 1).
